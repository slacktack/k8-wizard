# 10 — Extending Kubernetes & Production Patterns

> Go beyond built-in Kubernetes. This module covers CRDs and Operators, Service Mesh with Istio, Cilium and eBPF, policy-as-code with Kyverno/OPA, multi-cluster patterns, and the Kubernetes API in depth.

## Lessons

1. **CRDs & Operators** — Extend the Kubernetes API, build operators with kubebuilder
2. **Service Mesh with Istio** — Traffic management, mTLS, observability
3. **Cilium & eBPF** — eBPF-powered networking, observability, and security
4. **Policy as Code (Kyverno/OPA)** — Admission controllers, policy enforcement
5. **Multi-Cluster Patterns** — ClusterMesh, Karmada, ArgoCD ApplicationSet
6. **Kubernetes API Deep Dive** — API conventions, versioning, deprecation, watch semantics

## Prerequisites

- All previous modules completed
- A Kind cluster from [Module 02](../02-kubernetes-basics/README.md)
